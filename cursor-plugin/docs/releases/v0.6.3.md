# v0.6.3

Plan usage now also reads `GetSandUsageStatus`. That is the Grok Bot weekly window on the Cursor spending page (`usagePercent`, period start, next reset). `GetXaiUserUsageSnapshot` stays unauthorized for this login, so the plugin does not call it.

The status payload adds included spend and limit in cents, the plan price and display sentences from v0.6.2, and the Grok Bot fields. A failure of the weekly call leaves the plan numbers in place.

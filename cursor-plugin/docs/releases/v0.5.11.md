# Cursor plugin v0.5.11

Cursor plugin v0.5.11 reads official current-period usage for the authorized Cursor account and shows it on the management page.

## Changes

- Call Cursor dashboard `usage-summary`, `get-current-period-usage`, and `get-aggregated-usage-events` with the account session cookie and `Origin: https://cursor.com`.
- Display Cursor Models used dollars, official `autoPercentUsed`, and an estimated total only when that percentage is between 0 and 100 exclusive.
- Display Other Models guaranteed dollars (`plan.limit`), used dollars, and official `apiPercentUsed`.
- Keep plugin-process token estimates and request outcomes separate from Cursor billing.
- If dashboard usage cannot be read, show an unavailable state with the HTTP error instead of inventing a remaining-quota bar.

## Compatibility and upgrade

- The supported package remains Linux amd64 and the native CLIProxyAPI plugin ABI is unchanged.
- Existing credentials and model-disable settings require no migration.
- Restart CLIProxyAPI after upgrading so the management page loads the new usage fields.

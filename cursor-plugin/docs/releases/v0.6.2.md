# v0.6.2

Plan usage on the Cursor status page comes from `aiserver.v1.DashboardService/GetCurrentPeriodUsage`, `GetPlanInfo`, and `GetHardLimit` on `api2.cursor.sh`. That is the same data the Cursor agent CLI `/usage` command reads.

The plugin no longer registers as a request interceptor, so it is not handed every other provider's request body.
